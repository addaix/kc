# kc

**Knowledge Context** — machinery for making what an organisation knows
retrievable, attributable and usable by both humans and agents.

> **Status: design phase.** No implementation yet. This repository currently
> holds the research and the plan that will justify the first line of code.
> The PyPI name `kc` previously carried unrelated filtering utilities
> (≤ 0.0.7); the package is being repurposed from 0.0.8 onward.

## Where to start

| Document | What it holds |
|---|---|
| [`docs/notes-whitepaper.md`](docs/notes-whitepaper.md) | Notes mined from a vendor whitepaper on the category, with every claim tagged by evidential status |
| [`docs/research.md`](docs/research.md) | Literature review — organisational memory, knowledge management outcomes, ontology engineering, retrieval evaluation — including *what the evidence does not support* |
| [`docs/ecosystem.md`](docs/ecosystem.md) | Prior art, external and internal: what to depend on, wrap, study, or avoid |
| [`docs/plan.md`](docs/plan.md) | The minimal first version — scope, non-scope, and the seams |
| [`docs/open-decisions.md`](docs/open-decisions.md) | What is still undecided, and what evidence would settle each question |
